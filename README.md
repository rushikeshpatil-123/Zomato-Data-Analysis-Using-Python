# Zomato-Data-Analysis-Using-Python
## 📌 Project Overview

This project focuses on analyzing Zomato restaurant data using Python. The objective is to explore restaurant types, customer votes, ratings, online ordering availability, and approximate costs to understand patterns in the restaurant industry.

## 🎯 Project Objectives

- Analyze different types of restaurants.
- Identify restaurant types with the highest customer votes.
- Find the restaurant with the maximum number of votes.
- Analyze online order availability.
- Understand the distribution of restaurant ratings.
- Explore the approximate cost for two people.
- Compare ratings of restaurants that accept online orders with those that do not.
- Analyze online ordering availability across different restaurant types.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## 📂 Dataset

The project uses a Zomato restaurant dataset containing information about restaurant names, restaurant types, customer votes, ratings, online ordering availability, and approximate cost for two people.

**Dataset file:** `Zomato-data-.csv`

## 📊 Exploratory Data Analysis

### 1. Data Loading and Inspection
- Imported the dataset using Pandas.
- Examined the dataset structure and column information.
- Checked for missing values.

### 2. Data Cleaning
- Converted restaurant ratings into a numeric format.
- Prepared the data for analysis and visualization.

### 3. Restaurant Type Analysis
- Analyzed the distribution of different restaurant types.
- Visualized the number of restaurants in each category.

### 4. Votes Analysis
- Compared customer votes across restaurant types.
- Identified the restaurant with the maximum number of votes.

### 5. Online Order Analysis
- Analyzed restaurants based on online ordering availability.
- Compared online ordering availability across restaurant types.

### 6. Ratings Analysis
- Visualized the distribution of restaurant ratings.
- Compared ratings between restaurants that accept online orders and those that do not.

### 7. Cost Analysis
- Explored the approximate cost for two people.
- Visualized cost patterns in the dataset.

### 8. Data Visualization
Used Matplotlib and Seaborn to create charts, including:
- Count plots
- Bar charts
- Histograms
- Box plots
- Heatmaps
